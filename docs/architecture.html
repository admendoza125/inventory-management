System Architecture

Request Data Flow

1
User Interaction
User selects a filter or navigates to a view via Vue Router
→
2
Filter State
useFilters composable updates shared singleton refs
→
3
API Call
api.js builds query params and sends Axios GET to :8001
→
4
Server Filtering
FastAPI applies apply_filters() and filter_by_month() on in-memory data
→
5
Response
Pydantic validates, Vue computed properties derive display data

Key Patterns

Singleton Filter State

Filter refs are declared at module scope in useFilters.js, making them shared across all components that import the composable. Any view changing a filter triggers reactivity in all other views.

In-Memory Data Store

All JSON data is loaded once at server startup by mock_data.py. Endpoints filter in Python using list comprehensions. No database, no persistence across restarts.

Composition API Throughout

All components use Vue 3 Composition API with setup(). Reactive state in refs, derived data in computed properties. No Options API or mixins.

Centralized API Client

All HTTP calls go through api.js. Each method handles its own query param building, checking for 'all' values before appending. Views never call Axios directly.

Quarter-Aware Filtering

Backend supports both direct month (2025-01) and quarter (Q1-2025) filtering via QUARTER_MAP. Quarters expand to their constituent months for matching.

Locale-Aware Currency

useI18n composable auto-sets currency (USD/JPY) based on locale. currency.js handles conversion at 1 USD = 150 JPY with locale-appropriate formatting.
